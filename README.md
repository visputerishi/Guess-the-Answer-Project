# QuizUp – Online Quiz Application

## About the Project

QuizUp is a simple online quiz application that we created as part of our college project. The main idea behind this project is to make learning and testing knowledge more interesting through quizzes.

Users can choose from different categories, answer multiple-choice questions, and check their scores at the end. We have also added a timer to make the quiz more challenging.

## Features

- Five different quiz categories.
- Multiple-choice questions with four options.
- One question displayed at a time.
- Next and Previous buttons to move between questions.
- Selected answers are saved while navigating.
- Timer for every question.
- Questions automatically move to the next one when the timer runs out.
- Final score displayed after completing the quiz.
- Option to review answers.
- Restart option to play again.
- Simple and responsive design.

## Categories

The application currently includes these five categories:

1. General Knowledge
2. Science
3. Computer Science
4. Mathematics
5. Sports

Each category contains six questions.

## Timer

We have used different time limits for different categories:

| Category | Time per Question |

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the `index.html` file in your browser.
4. You can also use the Live Server extension in VS Code to run the application.

## How to Use

1. Open QuizUp in your browser.
2. Select the category you want to play.
3. Read each question and select one of the four options.
4. Use Next and Previous to move between questions.
5. Complete the quiz before the timer runs out.
6. Submit your answers and check your final score.
7. Review your answers or restart the quiz.
